# Student Records Filtering System
 
A system that helps school administrators rank and identify students based on set criteria, especially for scholarship screening.
 
## Description
 
Schools often struggle to rank students and find who qualifies for scholarships because records are searched and sorted by hand. The **Student Records Filtering System** stores student records and lets administrators quickly search, filter, rank, and check scholarship eligibility using efficient data structures and algorithms.
 
**Target users:** School administrators
 
## Features
 
- Add, update, and delete student records
- Search a student by ID
- View overall student rankings
- Filter students by Program, GWA, or Grade Range
- Check student eligibility for scholarships
